# 📊 Financial Sales Analysis Using Excel

An Excel-based data analysis project exploring financial performance across products, countries, customer segments, and years using **Microsoft Excel, PivotTables, PivotCharts, and slicers**.

---

## 📌 Project Overview

This project analyzes the Financial Sample dataset to compare sales, profit, discounts, and cost of goods sold (COGS) across products, countries, customer segments, and time periods.

The Excel project workbook contains PivotTable summaries and a dashboard designed to make financial comparisons easier to review.

## 🎯 Project Objectives

- Analyze sales, profit, discounts, and COGS.
- Compare profit across products and customer segments.
- Compare sales across countries and years.
- Summarize product-level sales, discounts, and profit.
- Use interactive slicers to explore the dashboard by segment, country, product, month, and year.

## 🗂 Dataset Description

The project uses the **Financial Sample** dataset with 700 transaction records and 16 fields in the project workbook.

Key fields include:

| Field | Description |
|---|---|
| `Segment` | Customer/business segment |
| `Country` | Country associated with the transaction |
| `Product` | Product name |
| `Discount Band` | Discount category |
| `Units Sold` | Units sold |
| `Manufacturing Price` | Manufacturing price |
| `Sale Price` | Sale price |
| `Gross Sales` | Gross sales amount |
| `Discounts` | Discount amount |
| `Sales` | Sales after discounts (stored in the source workbook as ` Sales`) |
| `COGS` | Cost of goods sold |
| `Profit` | Profit amount |
| `Date` | Transaction date |
| `Month Number` / `Month Name` | Month information |
| `Year` | Transaction year |

## 🛠 Tools & Excel Concepts

- **Microsoft Excel**
- PivotTables for summarizing financial data
- PivotCharts for visual comparisons
- Interactive slicers for filtering the dashboard
- Comparisons by product, country, segment, month, and year

## 🔄 Project Workflow

1. Open the Financial Sample dataset.
2. Review the transaction fields and financial measures.
3. Use PivotTables to group and summarize records.
4. Compare profit by product and segment, sales by country and year, and product-level sales, discounts, and profit.
5. Review the dashboard and explore the data using slicers.

## 📈 Key Findings

The figures below are taken from the project workbook and its accompanying presentation:

- **Total Sales:** $118,726,350.26
- **Total Profit:** $16,893,702.26
- **Highest-profit product:** Paseo — approximately $4,797,438
- **Highest-sales country:** United States of America — approximately $25,029,830
- **Highest-profit segment:** Government
- **Highest-sales year:** 2014


## 🖼️ Dashboard Preview

The dashboard brings together product-and-segment profit, sales by country, product-wise discounts and profit, and sales trends. Slicers are shown for Segment, Country, Product, Month Name, and Year.
